# WasteSort Project Plan

## Project Goal

WasteSort is an AI-powered computer vision system that identifies
common waste items and recommends an appropriate disposal category.

## MVP

Camera → ML Model → Waste Category → Display + LED

## Disposal Categories

- Recyclable
- Compost
- Landfill

## Stretch Goal

- Servo-controlled bin/lid
